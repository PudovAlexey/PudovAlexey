## 👋 Обо мне

**Senior Fullstack Developer, 8 лет в разработке.** Проектирую высоконагруженные системы и пишу fullstack в enterprise-домене — авиация и финтех.
Сейчас в Международном аэропорту **Шереметьево** веду разработку ключевых систем; одна из них — сервис цифрового двойника аэропорта — отмечена на выставке **ЦИПР 2024**.

## 🚀 Чем могу быть полезен

**🏗 Архитектура и system design на практике**
Спроектировал с нуля СУЗА/Waylot — polyglot-маркетплейс аэропортовых услуг: NestJS + Django + Go, Kafka KRaft, 11 изолированных Postgres БД. Архитектура C4 L1/L2 в PlantUML, 4 ADR. Свой NestJS AI-agent сервис с интеграцией Anthropic Claude (AI-модерация контента и автоперевод чатов).

**⚡ Высоконагруженные системы и performance**
В Сбере — транзакционная модель оплаты топлива на WebSocket с откликом **200 мс** и рендер карты **60 FPS** с 500+ маркерами АЗС (кастомные WebGL-оптимизации), кеш в IndexedDB → **−70% API-запросов**. Принятый PR в `react-data-grid` (баг виртуализации) → **−40%** задержки рендера. Свой движок виртуализации таблиц: **>1 000 колонок** и бесконечные строки без фризов на 4K.

**📦 Запуск продуктов и техническое лидерство**
Вывел систему оперативных расписаний для **2 000+ пользователей** за **3 недели** — от макетов до обучения сотрудников. Руковожу командой из **4+ разработчиков**: код-ревью, менторство, процессы.
